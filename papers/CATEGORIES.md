# Subject Categories — HTET 2024

The `Subject` column for Q91–150 must come from **this file only**. Never invent a
category, never let a session decide its own list — that is how the vocabulary drifts
and notes-to-PYQ linking breaks later.

Rules for every paper:
- Pick exactly one category per question, by **reading the question**, not by position.
- Every subject also allows `<Subject> Pedagogy` — questions about *teaching* the
  subject (method, assessment, classroom situation, misconception, lab/activity design).
  A pure content question is **not** pedagogy.
- If a question fits none of them, tag `REVIEW` and report the number. Never force-fit.
- Counts are never fixed. Do not balance them.

Q1–90 is the common section and is already extracted. Do not re-do it.
